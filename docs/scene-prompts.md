# Промты для генерации сцен

Подходят для Midjourney, DALL·E и других нейросетей. Готовые картинки сохраните как `public/scenes/t1.webp` … `t5.webp` (16:9, желательно 1920×1080).

**Нарушения рисуйте явно и крупно**, иначе их не будет видно на миниатюрах карточек.

## Общий стиль (добавлять к каждой сцене)

```
stylized 3D render, Pixar-like semi-realistic style, bright daylight colors, soft shadows, clean details, 16:9, view from behind/side of the worker, Kazakhstan rural village setting, worker in dark blue workwear with light-grey reflective stripes and white company logo on the back, no text, no letters
```

## Задание 1. Опора у здания АТС
Рядом стоит небольшое одноэтажное кирпичное здание сельской АТС, у него деревянная опора связи с открытым распределительным шкафом. Рабочий без каски, приставная лестница стоит под неправильным углом на неровной земле, инструмент разбросан, кабельный барабан не закреплён. Рядом белый служебный фургон, частные дома и синий деревянный забор.

## Задание 2. Крыша АТС
Рабочий на плоской крыше сельской АТС открыл шкаф оборудования. Каски нет, ограждения по краю крыши нет, страховочного пояса нет, кабель лежит петлями под ногами, ящик с инструментом стоит на краю. Видны крыши домов и степь.

## Задание 3. Вечер, опора у АТС
Сумерки, горит уличный фонарь. Рабочий на лестнице у опоры работает в шкафу без каски. Рядом проходит ЛЭП, провода низко. Зона работ не огорожена: стоят только два конуса, сигнальной ленты нет. Мусор и кабели лежат у основания.

## Задание 4. Аппаратный зал АТС
Внутри небольшой сельской АТС стоят стойки с оборудованием и жёлтыми кабелями. Рабочий без каски, соседняя стойка открыта без защитной крышки, на полу коробки, мотки кабеля и инструмент, проход загромождён стулом.

## Задание 5. Кабельный колодец у АТС
Колодец связи перед зданием АТС открыт, люк сдвинут. Рабочий спускается без страховки, ограждения и знаков вокруг колодца нет, газоанализатор не используется. Фургон стоит вплотную, рядом играют дети.
